# URBAN STRIKE — 모바일 FPS 슈팅게임

서든어택 느낌의 1인칭 슈팅게임입니다. 모바일 브라우저에서 바로 실행되며, 외부 라이브러리 없이 **단일 HTML 파일**로 동작합니다.

## 실행 방법

- `index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다.
- GitHub Pages로 배포하면 모바일에서 URL 접속만으로 플레이 가능합니다.
  (저장소 Settings → Pages → Branch 선택 → 저장)

## 조작법

### 📱 모바일
| 조작 | 방법 |
|---|---|
| 이동 | 화면 **왼쪽** 드래그 (가상 조이스틱) |
| 시점/조준 | 화면 **오른쪽** 드래그 |
| 사격 | **발사** 버튼 (소총은 꾹 누르면 연사) |
| 무기 전환 | **무기** 버튼 (소총 ↔ 저격총) |
| 저격 조준경 | **조준경** 버튼 (저격총 장착 시) |
| 수류탄 | **수류탄** 버튼 |
| 재장전 | **재장전** 버튼 |

### 🖥 PC
| 조작 | 방법 |
|---|---|
| 이동 | `W` `A` `S` `D` |
| 시점/조준 | 마우스 (화면 클릭으로 마우스 잠금) |
| 사격 | 마우스 왼쪽 클릭 |
| 무기 전환 | `1` 소총 / `2` 저격총 |
| 저격 조준경 | 마우스 **우클릭** |
| 수류탄 | `G` |
| 재장전 | `R` |

## 무기

| 무기 | 탄창 | 데미지 | 특징 |
|---|---|---|---|
| 소총 | 30발 | 26~40 | 연사 가능, 기동전에 유리 |
| 저격총 | 5발 | 100~150 | 한 방 처치, 조준경 줌(3.5배), 무빙 시 탄퍼짐 큼 |
| 수류탄 | 3개 시작 | 최대 170 (범위) | 웨이브마다 +1 보급 (최대 5), 벽에 튕김, 범위 폭발 |

## 게임 규칙

- **아군 분대원 2명**(파란 군복)이 함께 싸웁니다 — 적을 자동 교전하고 플레이어를 따라다닙니다.
- 아군이 전사해도 다음 웨이브에서 부활·회복됩니다.
- 웨이브마다 적 병사가 점점 많아지고 강해집니다. 적은 아군도 공격합니다.
- 적 처치 시 25% 확률로 **메드킷** 드랍 (HP +35), 웨이브 시작 시 맵 곳곳에 리필.
- 최대한 오래 살아남아 높은 킬 수를 기록하세요!

## 기술 구성

- **레이캐스팅 3D 엔진** (DDA 알고리즘, 캔버스 2D) — 32×32 대형 맵
- 절차 생성 텍스처 / 진영별 군인 스프라이트 (이미지 파일 없음)
- **BFS 유도 필드 경로찾기** — 적 추격 / 아군 합류 공용
- 수류탄 물리 (포물선 + 벽/바닥 반동) 및 범위 폭발 판정
- WebAudio 절차 생성 사운드 (총성·저격음·폭발음 등 15종)
- 멀티터치 지원 (이동 + 조준 + 사격 동시 입력)
