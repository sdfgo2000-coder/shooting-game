# URBAN STRIKE — 모바일 FPS 슈팅게임

서든어택 느낌의 1인칭 슈팅게임입니다. 모바일 브라우저에서 바로 실행되며, 외부 라이브러리 없이 **단일 HTML 파일**로 동작합니다.

## 실행 방법

- `index.html` 파일을 브라우저로 열면 바로 플레이할 수 있습니다.
- GitHub Pages로 배포하면 모바일에서 URL 접속만으로 플레이 가능합니다.
  (저장소 Settings → Pages → Branch 선택 → 저장)

## 조작법

### 📱 모바일
| 조작 | 방법 |
|---|---|
| 이동 | 화면 **왼쪽** 드래그 (가상 조이스틱) |
| 시점/조준 | 화면 **오른쪽** 드래그 |
| 사격 | **발사** 버튼 (꾹 누르면 연사) |
| 재장전 | **재장전** 버튼 |

### 🖥 PC
| 조작 | 방법 |
|---|---|
| 이동 | `W` `A` `S` `D` |
| 시점/조준 | 마우스 (화면 클릭으로 마우스 잠금) |
| 사격 | 마우스 왼쪽 클릭 |
| 재장전 | `R` |

## 게임 규칙

- 웨이브마다 적 병사가 점점 많아지고 강해집니다.
- 적을 처치하면 25% 확률로 **메드킷**을 떨어뜨립니다 (HP +35).
- 웨이브가 시작될 때마다 맵의 고정 위치에 메드킷이 리필됩니다.
- 최대한 오래 살아남아 높은 킬 수를 기록하세요!

## 기술 구성

- **레이캐스팅 3D 엔진** (DDA 알고리즘, 캔버스 2D)
- 절차 생성 텍스처 / 군인 스프라이트 (이미지 파일 없음)
- **BFS 유도 필드 경로찾기** — 적이 벽을 돌아 추격
- WebAudio 절차 생성 사운드 (총성·타격음·재장전 등)
- 멀티터치 지원 (이동 + 조준 + 사격 동시 입력)
